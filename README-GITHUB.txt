Estructura:
- index.html
- assets/images/ (galerias)

Este paquete está preparado para GitHub Pages y para subirlo mediante GitHub Desktop.

IMPORTANTE:
1. Descomprime este ZIP.
2. Crea o abre un repositorio local con GitHub Desktop.
3. Copia el CONTENIDO de esta carpeta al repositorio, dejando index.html en la raíz.
4. Haz Commit y Push.
5. En GitHub: Settings > Pages > Deploy from a branch > main / root.

No cambies los nombres ni las rutas de assets/images porque index.html las utiliza directamente.

Comprobación incluida: todas las rutas de imágenes referenciadas por index.html existen en el paquete.
